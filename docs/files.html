Six steps, two files

Describe your experiment in two files, then one command runs the steps in order. Click a step to see its files.

Every file, step by step

Follow one experiment from the command to the report. Each box is a real file of the code, and the links are read from the code itself.

  • Thick green line: the order of execution. cli.py starts the steps one after the other.
  • Thin arrow: one file calls another. Dashed: the call happens at run time, with no import.
  • Solid green: runs a step. Light green: a tool shared by many steps. White: helps one step. Links to shared tools appear when you click.
  • Dashed blocks: what the step reads and writes. <t>, <v>, <m>, <r> and <a> are the fingerprints of the table, variants, model, run and analysis.

Click a box: its explanation opens just below it.

Not drawn: empty __init__.py files, tests/, examples/ and tools/site/, which builds this site.

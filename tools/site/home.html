Get started

VLMShift is a program you run where your models and images are. Nothing is sent anywhere: the table, the images and the answers stay on your disk. Pick where to run it.

  • On your computer Python 3.10 or later. The demo runs CLIP on 100 photos, on a normal processor, in a few minutes. 
    git clone .git VLMShift
cd VLMShift
pip install -e ".[local]"
python examples/pope_mini/fetch.py
vlmshift all examples/pope_mini/experiment.yaml examples/pope_mini/analysis.yaml
    The tutorial, step by step
  • In your browser No graphics card? Google Colab and Kaggle lend one for free. The notebook runs both demos from the first cell to the last. Open the notebook in Colab The Colab and Kaggle guide
  • In a container Docker runs the whole tool on your machine with no account. Your folder is mounted, nothing leaves it. 
    docker build -t vlmshift --build-arg EXTRAS=local .
docker run --rm -v "$PWD:/work" vlmshift all experiment.yaml analysis.yaml
    Containers in the documentation

On a server with an NVIDIA card, see the server guide.

What it does

VLMShift checks whether a vision-language model keeps its answers when one or more conditions change, alone or combined: the language of the question, the source of the image, its quality…

  • Compare one or several models across any condition in your table.
  • Measure whether a model does worse, or changes its mind on the same images.
  • Trust the numbers: each one comes with its uncertainty, and the report says what could not be measured.
  • Work safely: stop at any time, resume, and rerun the analysis without calling the models.

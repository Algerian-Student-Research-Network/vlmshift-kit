Configuration reference

Every key the two configuration files accept, with its type, its default and its allowed values. This page is written from the schemas the code exports, so it always matches it: a key that is not here is refused.

Your editor can check the files as you type and suggest the keys. With the YAML extension of VS Code, write this first line in experiment.yaml (and the same with analysis in analysis.yaml):

# yaml-language-server: $schema=https://raw.githubusercontent.com/Algerian-Student-Research-Network/vlmshift-kit/main/docs/experiment.schema.json

A path such as models[].revision is the key revision of each entry of the list models; axes.<name>.type is the key type of each axis, under its name.
